# Formulas:

$$\log_X(A) = B \iff X^B = A$$

$$\log_A B = \frac{\log_C B}{\log_C A}$$

$$\log_X(AB) = \log_X A + \log_X B$$

$$\log_X\left(\frac{A}{B}\right) = \log_X A - \log_X B$$

$$\log_X(A^B) = B \cdot \log_X A$$

$$\log_X(1) = 0, \quad \log_X(X) = 1$$
